# ปูยางแอสฟัลท์ — ฉบับร่างรอรูปจากผู้ใช้

เส้นทางเมื่อพร้อมเผยแพร่: `/asphalt-paving/` ใช้รูปแบบและไฟล์ CSS/JavaScript ร่วมกับหน้า `/asphalt/` ล่าสุด

รูปที่อ้างอิงอยู่เป็นรูปเดิมชั่วคราว คำบรรยายและเครดิตยังอ้างอิงรูปจริงใน `/asphalt/` ต้องใส่รูปที่ผู้ใช้ส่งมาและข้อมูลรูปให้ครบก่อนเผยแพร่

ไฟล์อยู่ภายนอก `public/` จึงยังไม่ถูกเผยแพร่โดยคำสั่ง build/deploy เมื่อรูปพร้อม ให้นำหน้าไปไว้ใน `public/asphalt-paving/` และเปลี่ยน robots เป็น `index,follow` พร้อมเพิ่มทางเข้าและ sitemap
