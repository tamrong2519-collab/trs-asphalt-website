# TRS TAMRONGSAK CONSTRUCTION — เว็บไซต์ธุรกิจรับเหมางานผิวทาง

เว็บไซต์ภาษาไทย 4 หน้า ใช้ Vite และ JavaScript ไม่ต้องมีฐานข้อมูลหรือ backend รองรับมือถือ แท็บเล็ต และเดสก์ท็อป

มือถือทั้ง 4 หน้าใช้ viewport `width=device-width, initial-scale=1.0` เพื่อให้ตัวหนังสือแสดงตามขนาดจริง ข้อความทั่วไปอย่างน้อย 16px และหัวข้อ Hero 34–44px โดยคงสี รูปภาพ และดีไซน์เดิมของเว็บไซต์ การ์ดและข้อมูลติดต่อจัดตามความกว้างจอ ปุ่มหลักมีพื้นที่แตะอย่างน้อย 52px และยังใช้สองนิ้วซูมได้ ส่วนคอมพิวเตอร์คงการจัดวางเดิม

ทดสอบด้วย mobile emulation ที่เปิด `isMobile: true` และ `hasTouch: true` ที่ 320, 375, 390 และ 430px ใน `tests/mobile-responsive.spec.js` ตรวจขนาดข้อความ พื้นที่แตะ เมนู ช่องทางติดต่อ หน้าจอไม่ล้น สไลด์อัตโนมัติ และการซูม

### เพิ่มผลงานหลายรูป

หน้าผลงานใช้แบบภาพคู่รายละเอียด สลับซ้าย–ขวาบนคอม และวางภาพเหนือข้อความบนมือถือ งานลาดยางมะตอยอยู่รายการแรก แต่ละโครงการมีภาพหน้าปกหนึ่งรูปและเปิดดูรูปทั้งชุดได้

ปุ่มกรองผลงานทั้ง 6 หมวดใช้สี่เหลี่ยมมุมมนขนาดเท่ากัน สูงอย่างน้อย 48px ตัวอักษร 15px จัด 6 คอลัมน์บนคอมพิวเตอร์ 3 คอลัมน์บนแท็บเล็ต และ 2 คอลัมน์บนมือถือ ปรับได้ใน `src/projects-paired.css`

เพิ่มรายการใน `projects` ของ `src/data.js` โดยเก็บรายการลาดยางไว้ก่อน เช่น:

```js
{
  id: 'project-01', // ชื่ออ้างอิงของชุดภาพ ไม่ซ้ำรายการอื่น
  title: 'ชื่อโครงการจริง',
  category: 'asphalt', // asphalt / gravel / stone / speed-bump / marking
  location: 'พื้นที่โครงการ', // เว้นว่างได้ หากยังไม่มีข้อมูล
  description: 'รายละเอียดงานจริง',
  images: [
    { src: '/images/project-01.webp', alt: 'รายละเอียดภาพหน้าปก' },
    { src: '/images/project-02.webp', alt: 'รายละเอียดภาพหน้างานรูปที่สอง' },
  ],
}
```

รูปแรกเป็นหน้าปก เพิ่มรูปได้หลายรูปใน `images` โดยจะอยู่ในแกลเลอรีชุดเดียวกัน รองรับปุ่มก่อนหน้า/ถัดไป ปุ่มลูกศรบนคีย์บอร์ด การปัดบนมือถือ และ Escape เพื่อปิด ภาพปกมีสัดส่วน 3:2 และมุมมน 16px ภายในแกลเลอรีแสดงภาพเต็มโดยไม่ตัดขอบ

หน้าผลงานทั้ง 5 ประเภทใช้รูปหน้างานที่ผู้ใช้ส่งมา ชุดลาดยางมะตอยมี 14 รูป (`asphalt-job-01.webp` เป็นหน้าปก และ `asphalt-job-02.webp` ถึง `asphalt-job-14.webp` เป็นรูปเพิ่มเติม) รูปแปลงเป็น WebP โดยเก็บความละเอียดและสัดส่วนเดิม: รูป 01–08 ขนาด 1280×960px รูป 09 ขนาด 1280×720px และรูปแนวตั้ง 10–14 ขนาด 960×1280px

ชุดลานจอดรถหินคลุกมี 11 รูป (`gravel-job.webp` เป็นหน้าปก ตามด้วย `gravel-slide.webp` และ `gravel-job-03.webp` ถึง `gravel-job-11.webp`) รูปเพิ่มเติมเก็บความละเอียดเดิม 1280×960px ยกเว้นรูป 05–06 และ 09 ซึ่งเป็นแนวตั้ง 960×1280px แกลเลอรีแสดงภาพเต็มโดยไม่ตัดขอบ

งานหินเกล็ดรวมอยู่ในชุด `stone-yard` เดียวทั้งหมด 15 รูป เรียงจากงานลาน 6 รูป (`stone-job.webp` เป็นหน้าปก ตามด้วย `stone-job-02.webp` ถึง `stone-job-06.webp`) ความละเอียดเดิม 1280×960px ตามด้วยงานรอบอาคาร 4 รูป (`stone-building-01.webp` ถึง `stone-building-04.webp`) แนวตั้ง 963×1280px และงานรอบบ้าน 5 รูป (`stone-home-01.webp` ถึง `stone-home-05.webp`) รูป 01, 03 และ 05 เป็นแนวตั้ง 960×1280px ส่วนรูป 02 และ 04 เป็นแนวนอน 1280×960px

งานลูกระนาดยางมะตอยมี 8 รูป (`speed-bump-job.webp` เป็นหน้าปก 1280×960px ตามด้วย `speed-bump-job-02.webp` ถึง `speed-bump-job-05.webp` แนวตั้ง 960×1280px และ `speed-bump-job-06.webp` ถึง `speed-bump-job-08.webp` แนวนอน 1280×960px) ภาพที่ส่งซ้ำกับหน้าปกหรือซ้ำกันในชุดจะเก็บเพียงครั้งเดียว รูปทั้งหมดแสดงเต็มในแกลเลอรี

งานตีเส้นจราจรมี 11 รูป (`marking-job.webp` เป็นหน้าปก ตามด้วย `marking-job-02.webp` ถึง `marking-job-11.webp`) รูป 07–08 เป็นแนวตั้ง 960×1280px ส่วนรูปอื่นเป็นแนวนอน 1280×960px รวมภาพช่องจอดรถ ช่องจอดสำหรับผู้ใช้รถเข็น เส้นขอบทาง เส้นบริเวณทางโค้ง เส้นแบ่งช่องทางเดินรถ และลูกศรบอกทิศทาง โดยไม่เพิ่มภาพปกที่ส่งซ้ำ รูปทั้งหมดแสดงเต็มในแกลเลอรี โลโก้จริงอยู่ที่ `public/images/logo.webp`

แต่ละชุดภาพมี `id` ไม่ซ้ำกัน ใช้เปิดลิงก์ตรงถึงผลงานได้ เช่น `projects.html#stone-yard` ตัวกรองประเภทงานจะแสดงทุกชุดในหมวดที่เลือก ลิงก์เดิม `#stone-building-yard` และ `#stone-home-yard` จะเปิดชุดงานหินเกล็ดที่รวมแล้ว โดยกำหนดชื่อเดิมไว้ใน `anchorAliases`

## การขอประเมินราคา

หน้าติดต่อเราวางส่วนที่ตั้งบริษัทไว้ท้ายเนื้อหา หลังส่วนขอประเมินราคาและก่อน Footer ใช้กรอบสีฟ้าอ่อน การ์ดข้อมูลสีขาวมุมมน ที่อยู่และเบอร์สอบถามเส้นทาง พร้อมแผนที่ Google Maps บนมือถือการ์ดอยู่เหนือแผนที่ ปุ่มสีน้ำเงิน “เปิดเส้นทางใน Google Maps” อยู่ใต้แผนที่เพื่อให้ข้อมูลของ Google แสดงครบ รูปแบบอยู่ใน `src/company-location.css` ที่อยู่และจุดค้นหาแผนที่ใช้ `address` และ `mapLocation` ใน `src/data.js`

ฟอร์มตรวจข้อมูลจำเป็นแล้วสร้างข้อความในเครื่องของผู้ใช้ ให้คัดลอกข้อความ เปิด LINE หรือส่งผ่านแอปอีเมล (เมื่อกำหนดช่องทางแล้ว) ไม่มีการส่งอัตโนมัติ ไม่มีการบันทึกข้อมูลบนเซิร์ฟเวอร์ หากต้องการรับข้อมูลผ่านเว็บไซต์โดยตรง ต้องเชื่อมต่อ backend หรือผู้ให้บริการฟอร์มเพิ่มเติม

## ดีไซน์ตาม Reference

ใช้โทนขาว น้ำเงินเข้ม และฟ้าสด Header พร้อมเบอร์โทร Hero ภาพเต็มความกว้าง การ์ดบริการ 5 ประเภท (แยกหินคลุกกับหินเกล็ด) แกลเลอรี 3+2 บนเดสก์ท็อป หน้าติดต่อแบบภาพคู่ข้อมูล ปุ่มลอยโทร/LINE และ Footer ลายเฉียงฟ้า รองรับหน้าจอ 320px ขึ้นไป ภาพตัวอย่างถูกบีบอัดเป็น WebP และใช้ซ้ำเพื่อประหยัดการโหลด

### การอ่านและแตะบนมือถือ

ข้อความทั่วไปบนมือถือ 16px ขึ้นไป Hero 34–44px พร้อมคำอธิบาย 19–20px การ์ดเรียงคอลัมน์เดียว ปุ่มหลักสูง 56px หน้าติดต่อใช้ปุ่มโทรสีน้ำเงินเข้มและ LINE สีเขียววางซ้อนกัน ขอบมน 16px ตัวอักษร 17–18px ปุ่มลอยถูกซ่อนเฉพาะหน้าติดต่อบนมือถือเพื่อไม่ให้ซ้ำกัน การทดสอบตรวจขนาดตัวอักษร ปุ่มไม่ตัดข้อความ ระยะขอบ และหน้าจอไม่ล้น

### สไลด์หน้าแรกแบบพรีเมียม

Hero หน้าแรกใช้ภาพเต็มความกว้าง เงาน้ำเงินเข้ม หัวข้อ Noto Sans Thai ขาว–ฟ้า และปุ่มขอประเมินราคาฟรี สไลด์ 5 ภาพเปลี่ยนอัตโนมัติทุก 6 วินาทีด้วย Crossfade 750ms มีลูกศร เลขสไลด์ และปุ่มพัก โดยไม่มีจุดบอกตำแหน่ง รองรับการปัดบนมือถือ หยุดเมื่อกำลังใช้งานหรือเปิดหน้าอื่น ผู้ใช้ที่ตั้งลดการเคลื่อนไหวจะเริ่มแบบพักและไม่มีเอฟเฟกต์ ส่วนอื่นของเว็บไซต์ใช้ดีไซน์เดิม

### หัวเว็บ

ใช้ส่วนหัวแบบที่ 7 ร่วมกันทั้ง 4 หน้า: โลโก้บนพื้นน้ำเงิน เมนูบนแถบทอง และโทร/LINE บนพื้นขาว ส่วนหัวตรึงด้านบน โลโก้มือถืออยู่กึ่งกลาง เมนูชื่อเต็มแสดงครบ และช่องติดต่อมีพื้นที่แตะอย่างน้อย 44px ดูรายละเอียดและตำแหน่งไฟล์ในหัวข้อ “ส่วนหัวเว็บแบบที่ 7 · น้ำเงิน–ทอง” ด้านล่าง

### ฟอนต์และน้ำหนักตัวอักษร

ใช้ Noto Sans Thai แบบเสิร์ฟจากเว็บไซต์เองทั้ง 4 หน้า ข้อความทั่วไปน้ำหนัก 400 เมนูและปุ่ม 500 หัวข้อการ์ด 600 หัวข้อหลักและหัวข้อส่วนต่าง ๆ 700 คำอธิบายและช่องกรอกข้อมูลมีขนาดอย่างน้อย 16px ระยะห่างบรรทัด 1.65–1.8 และจัดคำไทยโดยไม่เพิ่มระยะระหว่างตัวอักษร ปรับรูปแบบรวมได้ใน `src/typography.css` ส่วนปุ่มโทรและ LINE ขนาดเล็กใน Header คงขนาดล่าสุด

### หน้าแรกตาม Reference ล่าสุด

หน้าแรกใช้ส่วนหัวร่วมแบบที่ 7 พร้อมเมนูและช่องโทร/LINE ส่วน Hero สัดส่วนประมาณ 2.64:1 บนคอมพิวเตอร์ หัวข้อขาว–ฟ้า ลูกศรด้านข้างและปุ่มประเมินหน้างานฟรี โดยเอาจุดบอกตำแหน่งสไลด์ออก แถบจุดเด่น 3 ข้อ การ์ดบริการ 5 ใบ ผลงานแบบ 3+2 และ Footer ขาวพร้อมลายเฉียง ใช้รูปหน้างานเดิมและ Noto Sans Thai ส่วนหน้าอื่นคงเดิม ปรับได้ใน `src/home-reference.css` มือถือเรียงการ์ดคอลัมน์เดียว ข้อความทั่วไป 16px ขึ้นไป และปุ่มแตะได้สะดวก

### รูปผลงานหน้าแรก

การ์ดผลงานทั้ง 5 ใบมีขนาดเท่ากัน ใช้ภาพสัดส่วน 16:10 และครอปโดยรักษาสัดส่วนภาพ บนคอมพิวเตอร์จัด 3 ใบแถวแรกและ 2 ใบกึ่งกลางแถวล่าง แท็บเล็ตใช้ 2 คอลัมน์พร้อมใบสุดท้ายกึ่งกลาง มือถือเรียงคอลัมน์เดียว เปลี่ยนภาพได้ใน `src/data.js` และปรับการจัดวางใน `src/home-reference.css`

กรอบรูปบริการ รูปผลงาน รูปติดต่อ และภาพขยายทั้ง 4 หน้าใช้สี่เหลี่ยมมุมมน 16px ปรับมุมมนร่วมกันได้ที่ `--photo-radius` ใน `src/photo-frames.css` ส่วนภาพด้านบนสุดและสไลด์ใช้มุมเหลี่ยมเต็มความกว้างเหมือนเดิม

### ลูกศร

ใช้ SVG เส้นบางที่กำหนดใน `src/main.js` และจัดรูปแบบใน `src/arrows.css` การ์ดใช้หัวลูกศรสีฟ้า ปุ่มใช้ลูกศรตรง สไลด์ใช้หัวลูกศรสีขาว บนคอมพิวเตอร์มีการเลื่อนลูกศร 3px เมื่อชี้เมาส์ บนมือถือซ่อนปุ่มก่อนหน้า ถัดไป และเล่น/หยุด สไลด์ยังเปลี่ยนอัตโนมัติทุก 6 วินาทีและปัดเลื่อนด้วยนิ้วได้ รองรับการตั้งค่าลดการเคลื่อนไหว

### Hero ขาว–ฟ้าและปุ่มโทรสีฟ้า

Hero หน้าแรกใช้ข้อความตามภาพล่าสุด: “รับเหมาลาดยางมะตอย และงานหินคลุกครบวงจร” พร้อมคำอธิบาย 3 บรรทัด จุดเด่น 4 ข้อ ปุ่มสีฟ้า “โทร 062-248-4089” ที่กดโทรได้ทันที และข้อความประเมินเบื้องต้นฟรี รูปแบบอยู่ใน `src/hero-estimate.css` ภาพ `hero-sharp.webp` เป็นภาพประกอบที่ปรับใหม่ให้เครื่องจักรใหญ่ขึ้นและรายละเอียดพื้นถนนคมชัด ลดการบีบอัดไฟล์ภาพด้วย WebP คุณภาพ 96 และใช้ `hero-sharp-mobile.webp` ขนาด 960×640px สำหรับจอเล็กผ่าน `srcset` บนคอมพิวเตอร์จำกัดเงาขาวไว้ด้านข้อความและปล่อยภาพด้านขวาให้เห็นสีจริง บนมือถือแสดงภาพสูง 230–290px เหนือข้อความโดยไม่มีเงาขาวทับภาพ เพื่อให้เห็นเครื่องจักรและภาพหน้างานชัดเจนทั้ง 5 สไลด์ ซ่อนตัวควบคุมสไลด์บนมือถือที่ความกว้างไม่เกิน 760px เพื่อให้เห็นภาพเต็ม โดยยังแสดงปุ่มควบคุมบนจอที่ใหญ่กว่า สไลด์ยังเปลี่ยนอัตโนมัติ 5 ภาพ โดยจองพื้นที่ข้อความให้ความสูงคงที่บนมือถือ


### ส่วนหัวเว็บแบบที่ 7 · น้ำเงิน–ทอง

ส่วนหัวทั้ง 4 หน้าใช้แบบที่ 7: แถวโลโก้พื้นน้ำเงิน `#164f9f` แถบเมนูสีทอง `#e0bc68` พร้อมเส้นใต้สีน้ำเงินสำหรับหน้าปัจจุบัน และแถวโทร/LINE พื้นขาว บนคอมพิวเตอร์โลโก้อยู่ซ้ายและข้อความบริษัทอยู่ขวา บนมือถือวางโลโก้กึ่งกลาง เมนูชื่อเต็มทั้ง 4 หน้ายังคงแสดงทันทีและรองรับคีย์บอร์ด ช่องติดต่อกว้างเท่ากัน มีเส้นทองคั่น ไอคอนขนาด 18px พื้นที่แตะสูงอย่างน้อย 44px และชื่อที่อ่านด้วยโปรแกรมอ่านหน้าจอระบุโทรและ LINE ชัดเจน

รูปแบบอยู่ใน `src/navigation.css` และโครงสร้างอยู่ใน `src/main.js` ใช้ ResizeObserver วัดความสูงส่วนหัวเพื่อให้ลิงก์ไปยังผลงาน บริการ และฟอร์มประเมินราคาเลื่อนไปยังตำแหน่งที่ไม่ถูกส่วนหัวบัง รูปแบบ Footer และปุ่มลอยใช้ไฟล์แยกตามเดิม

### การจัดตัวอักษรหน้าแรก

คงฟอนต์ Noto Sans Thai และข้อความ Hero เดิม แบ่งหัวข้อเป็นวลีเพื่อไม่ให้คำว่า “มะตอย” หลุดไปอยู่บรรทัดเดียว บนมือถือข้อความรองในหัวข้อมีขนาดเล็กกว่าหัวข้อหลัก คำอธิบายไหลตามความกว้างจอโดยไม่บังคับขึ้นบรรทัดแบบคอมพิวเตอร์ รายละเอียดทุกส่วนของหน้าแรกมีขนาดอย่างน้อย 16px รวมถึงช่วงแท็บเล็ต การ์ดบนคอมพิวเตอร์ใช้ความกว้างเต็มใต้ไอคอน ส่วนบนมือถือจัดคอลัมน์ข้อความให้ขยายเต็มพื้นที่ ปรับได้ใน `src/home-reference.css` และ `src/hero-estimate.css` การทดสอบ `tests/home-typography.spec.js` ตรวจการอ่านและข้อความล้นที่ 320, 375, 390, 430, 768, 853, 1024 และ 1440px พร้อมตรวจความสูงคงที่ครบทั้ง 5 สไลด์

### Footer แบบที่ 5

ส่วนท้ายทั้ง 4 หน้าใช้พื้นขาวอมเทา โลโก้และชื่อบริษัทเรียงสามบรรทัด ข้อความสั้น ปุ่มโทร/LINE ทรงแคปซูลขนาดเท่ากัน เมนูครบ 4 หน้า พื้นที่ให้บริการ และลิขสิทธิ์ พร้อมแถบลายเฉียงฟ้าสูง 8px มือถือเรียงช่องทางติดต่อเต็มความกว้างและเผื่อพื้นที่ให้ปุ่มลอย บนคอมพิวเตอร์ปุ่มลอยจะซ่อนเมื่อ Footer อยู่ในหน้าจอเพื่อไม่ให้ทับข้อมูล ปรับรูปแบบได้ใน `src/footer.css` ข้อมูลติดต่อยังแก้ได้จาก `src/data.js`

การจัดวาง Footer ตรงกับภาพตัวอย่างแบบที่ 5: กรอบมุมมนกว้างสูงสุด 1288px แถวบนใช้ Flex กระจายโลโก้ ข้อความ และปุ่มติดต่อสามส่วน ระยะขอบด้านใน 36px บนคอมและ 22px บนมือถือ เมนูมือถือเรียงและขึ้นแถวตามพื้นที่เหมือนตัวอย่าง พื้นที่เผื่อปุ่มลอยอยู่ด้านนอกกรอบ

### ธีมน้ำเงิน–ทองทั้ง 4 หน้า

ใช้ตัวอย่างแบบที่ 3 เป็นแนวทาง: น้ำเงินเข้ม `#091f59`, ทอง `#f0d68c` และพื้นขาวงาช้าง `#fbf8ef` จัดสี ระยะห่าง การ์ด ช่องทางติดต่อ และส่วนท้ายให้เข้าชุดกันทั้งหน้าแรก บริการ ผลงาน และติดต่อ ปรับรูปแบบรวมได้ใน `src/premium-theme.css` ซึ่งโหลดหลัง CSS เดิม

รูปหินคลุก หินเกล็ด ลูกระนาด และตีเส้นที่ผู้ใช้ส่งมาแสดงในหน้าบริการและหน้าผลงานด้วย เปิดภาพใหญ่และกรองประเภทได้ ภาพลาดยางใช้ภาพประกอบ สไลด์หน้าแรกยังเปลี่ยนอัตโนมัติ 5 ภาพโดยไม่มีจุดบอกตำแหน่ง ข้อมูลบริษัทและรูปบริการแก้ได้ใน `src/data.js`

มือถือใช้ข้อความอย่างน้อย 16px, หัวข้อหลัก 34–44px และปุ่มติดต่อที่แตะได้สะดวก พร้อมจัดระยะให้ปุ่มลอยไม่ทับส่วนท้าย หน้าติดต่อยังใช้ปุ่มในหน้าโดยซ่อนปุ่มลอยบนมือถือ

### หน้าบริการแบบภาพคู่ข้อความ

หน้าบริการใช้ตัวอย่างแบบที่ 1: ภาพและรายละเอียดสลับซ้าย–ขวาบนคอมพิวเตอร์ ส่วนมือถือวางภาพเหนือข้อความทุกบริการ ภาพใช้กรอบมุมมนขนาดเท่ากัน พร้อมคำอธิบายสั้น รายละเอียดงาน 3 ข้อ และปุ่ม “ขอประเมินงานนี้” ทั้ง 5 ปุ่มที่ลิงก์ไปหน้าติดต่อเรา ตามด้วยขั้นตอนการให้บริการและช่องทางโทร/LINE

แก้รูปและรายละเอียดได้ใน `src/data.js` และปรับการจัดวางเฉพาะหน้านี้ใน `src/services-paired.css` ซึ่งโหลดหลังธีมหลัก โดย Header, Footer และปุ่มลอยยังใช้ส่วนประกอบร่วมของทั้ง 4 หน้า

### ปุ่มติดต่อบนมือถือ

ปุ่มลอยด้านล่างบนมือถือใช้กรอบสีขาวมุมมนกึ่งกลางจอ กว้างสูงสุด 360px เว้นขอบซ้าย–ขวาอย่างน้อย 16px และห่างขอบล่าง 12px พร้อมรองรับ safe area ปุ่มโทร/LINE ทรงแคปซูลสูง 48px ตัวอักษร 18px เว้นระหว่างปุ่ม 12px ส่วนหน้าติดต่อยังซ่อนปุ่มลอยเพื่อไม่ให้ซ้ำกับปุ่มในหน้า
